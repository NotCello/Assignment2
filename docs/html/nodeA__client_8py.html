Detailed Description

A ROS action client for sending movement goals to the robot.

Author
Marcello Ori
Version
1.0
Date
12/03/2025

This script implements a ROS action client that allows users to set movement goals for the robot. It continuously retrieves the robot's current state from the /odom topic and publishes updates to the /robot_status topic. The user can:

  • Set a movement goal through input
  • Cancel an active goal if needed
  • Exit the program gracefully

Publisher:

  • /robot_status

Subscriber:

  • /odom

Action Client:

  • /reaching_goal
