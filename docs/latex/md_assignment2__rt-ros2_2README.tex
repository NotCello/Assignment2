This project involves creating a ROS 2 package named {\ttfamily assignment2\+\_\+rt} that enables controlling a robot in a simulation environment. The functionality allows users to set linear and angular velocities, moving the robot for 3 seconds per command until the program is terminated.\hypertarget{md_assignment2__rt-ros2_2README_autotoc_md2}{}\doxysubsection{\texorpdfstring{Node Functionality}{Node Functionality}}\label{md_assignment2__rt-ros2_2README_autotoc_md2}
The program consists of a single node that interacts with the user through the terminal to control the robot\textquotesingle{}s motion\+:
\begin{DoxyItemize}
\item {\bfseries{User Input}}\+: At each step, the user is prompted to provide\+:
\begin{DoxyItemize}
\item Linear velocity ({\ttfamily x})
\item Angular velocity ({\ttfamily z})
\end{DoxyItemize}
\item {\bfseries{Robot Motion}}\+: The robot moves with the specified velocities for 3 seconds.
\item {\bfseries{Termination}}\+: The program runs continuously until the user interrupts it.
\end{DoxyItemize}

The robot starts in the simulation environment at position {\ttfamily (2,2)}.\hypertarget{md_assignment2__rt-ros2_2README_autotoc_md3}{}\doxysection{\texorpdfstring{Nodes Description}{Nodes Description}}\label{md_assignment2__rt-ros2_2README_autotoc_md3}
\hypertarget{md_assignment2__rt-ros2_2README_autotoc_md4}{}\doxysubsection{\texorpdfstring{Movement Node}{Movement Node}}\label{md_assignment2__rt-ros2_2README_autotoc_md4}
This single node interacts with the user and commands the robot\+:
\begin{DoxyItemize}
\item {\bfseries{User Commands}}\+:
\begin{DoxyItemize}
\item Enter the desired linear velocity ({\ttfamily x}) and angular velocity ({\ttfamily z}).
\end{DoxyItemize}
\item {\bfseries{Robot Behavior}}\+:
\begin{DoxyItemize}
\item Upon receiving input, the robot moves in the simulation environment with the given velocities for 3 seconds.
\end{DoxyItemize}
\end{DoxyItemize}

This node uses ROS 2 publisher to control the robot’s movement, publishing velocity data on the {\ttfamily /cmd\+\_\+vel} topic.\hypertarget{md_assignment2__rt-ros2_2README_autotoc_md5}{}\doxysection{\texorpdfstring{Installation}{Installation}}\label{md_assignment2__rt-ros2_2README_autotoc_md5}
