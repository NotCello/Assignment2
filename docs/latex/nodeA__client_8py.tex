\doxysubsection{Detailed Description}
A ROS action client for sending movement goals to the robot. 

\begin{DoxyAuthor}{Author}
Marcello Ori 
\end{DoxyAuthor}
\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
12/03/2025
\end{DoxyDate}
This script implements a ROS action client that allows users to set movement goals for the robot. It continuously retrieves the robot\textquotesingle{}s current state from the {\ttfamily /odom} topic and publishes updates to the {\ttfamily /robot\+\_\+status} topic. The user can\+:
\begin{DoxyItemize}
\item Set a movement goal through input
\item Cancel an active goal if needed
\item Exit the program gracefully
\end{DoxyItemize}
