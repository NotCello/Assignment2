Detailed Description

A ROS service node for retrieving the latest goal set for the robot.

Author
Marcello Ori
Version
1.0
Date
12/03/2025

This service node keeps track of the most recent goal sent to the robot. It subscribes to the /reaching_goal/goal topic to store the latest goal, and provides a service at /retrieve_latest_goal to return the last goal set.

Subscriber:

  • /reaching_goal/goal

Service:

  • /retrieve_latest_goal
